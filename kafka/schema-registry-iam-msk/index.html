配置Confluent Schema Registry使用IAM认证连通AWS MSK

原创付费分类：Kafka发表于：2023-06-24阅读用时：7 分钟 (约 1026 字)阅读：0

Confluent Schema Registry 在运行时需要连通Kafka集群进行一些必要的操作，例如Confluent Schema Registry会在Kafka上创建并使用一个名为 _schemas 的Topic。另一方面，AWS MSK推荐使用的认证方式是IAM，这是开源 Kafka 集群所不具有的特性。当我们需要将Confluent Schema Registry和AWS MSK结合起来一起使用时，就会遇到一个技术问题：如何配置Confluent Schema Registry使用IAM认证连通AWS MSK，本文会针对这一问题给出解决方案。备注：本文我们以Docker形式来介绍和验证环境的搭建。

1. 定制Confluent Schema Registry 镜像

Confluent官方有提供的Schema Registry Docker Image ，在DockerHub上的Repository是: confluentinc/cp-schema-registry ，通常情况下是可以直接使用的。但是，如果要使用IAM认证和AWS MSK连通的话，需要在MSK的客户端，即此场景下Confluent Schema Registry上安装用于完成IAM认证的 类 库： aws-msk-iam-auth ，项目地址： https://github.com/aws/aws-msk-iam-auth 。项目提供了一个All-In-One的Fat Jar，下载后直接放置到Schema Registry Docker指定的类库文件夹中即可。所以，我们需要集成官方的Docker Image，然后安装上 aws-msk-iam-auth 类库，并打出一个新的Docker Image。操作脚本如下：
