Flink Temporal Join 系列 (1)：用 Temporal Table DDL 实现基于事件时间的关联

原创付费分类：Flink发表于：2024-03-19阅读用时：4 分钟 (约 603 字)阅读：0

本文要演示的是：使用 Temporal Table DDL 定义被关联表（维表），然后基于主动关联表（事实表）的“事件时间”去进行Temporal Join（关联时间维度上对应版本的维表数据）。该演示涉及三个要点：

  • 被关联的表（维表）是用 Temporal Table DDL 形式定义，必须是一张时态表（版本表）

  • 主动关联的表（事实表）需要定义”事件时间“属性，但并不需要是一张时态表（版本表）

  • Temporal Join 是使用 Temporal Table DDL + FOR SYSTEM_TIME AS OF 关键字实现的
