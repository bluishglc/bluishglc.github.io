Laurence 的技术博客

本站点于 2026 年 11 月建立，在此时间点之前的 680 篇文章为博主在 CSDN 博客上的原创文章，建站时整体迁移到了这里。离开 CSDN 时，博客的访问量是 680 万，粉丝 6582 人，鉴于 CSDN 早已堕落，这些数据并不值得夸耀，只是作为这个站点的前身，记录下交接时的状况。AI 崛起之后，人们已不再去互联网上搜索和阅读文章，所以，这个博客注定不会再复曾经的熙熙攘攘，于我个人而言，撰写文章是我的一种学习方式，无论是否还有读者，大概率还是会写下去的。

博主于 2007 年开始在 CSDN 上撰写技术文章，成为了最早一批的博客专家，之后，陆续在《程序员》杂志、DSDN、InfoQ、DataZone、AWS Blog 以及 Hudi、HBase 等产品公众号上发表过文章。早期主要从事基于 Java 的 Web 应用开发，后来转入大数据领域，主导过多个大型平台的建设，2020 年出版《大数据平台架构与原型实现：数据中台建设实战》一书，目前在学习和使用 Rust。喜欢徒步，走过华东的千八、七尖以及很多路线，高海拔徒步去过扎尕那。每年都期待一次长途旅行，见过最美的风景是喀拉峻大草原。旅行是困苦工作和生活的一杯加糖拿铁，解不了什么问题，却可以让人短暂快乐一阵子。人生也是一场旅行，这博客是我游记的一部分。以下收录了博主公开发表过的作品链接以及对应的本站链接。
