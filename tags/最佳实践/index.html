在 Amazon EMR Serverless 上提交作业时，把作业描述直接写在命令行里，作业一复杂就会遇到各种麻烦。本文以 Apache Hudi DeltaStreamer CDC 作业为参考范本，总结出八项最佳实践：集中配置环境相关变量以提升可移植性；为作业建立专用工作目录和 S3 桶；用 cat 加 heredoc 生成作业描述文件，规避 shell 与 json 的双重转义；在描述文件中嵌入 shell 变量和脚本实现动态构建；用 jq 校验并格式化 json；以及可复用的 S3 Jar 包路径拼接、作业监控和日志错误检索脚本。
