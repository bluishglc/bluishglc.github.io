桌面应用静态资源文件的部署方式：Install-Time Copy 和 Runtime Copy

原创付费分类：Qt发表于：2026-04-15阅读用时：8 分钟 (约 1194 字)阅读：0

桌面 应用开发 中的一个典型问题：在桌面应用中经常会使用到一些静态资源文件，例如某类模板文件、只读的配置文件，这些资源文件一般都是只读的，应用只会读取其中的内容，并不会修改它们，但是在程序升级时，它们的内容可能会发生变更，需要覆盖。此类文件有两种部署方式：

  • 通用应用安装包部署：通过安装程序（MSI / Setup.exe / Inno Setup / ClickOnce）把默认模板、配置文件直接写入 %APPDATA%\YourApp\… 目录，此方法可以称为：安装时复制（Install-Time Copy）

  • 在程序启动时从程序中复制：当程序启动时时主动检查 %APPDATA%\YourApp 目录是否存在，如不存在，就将文件就从应用程序中（一般是内嵌在 exe 中的二进制资源文件）复制过去，此方法可以称为：运行时复制（Runtime Copy）
